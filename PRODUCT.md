# Product

## Platform

web

## Product Purpose

Resume Builder supports private resume upload and factual review, matching to a job description, editing and formatted export, and job discovery/activity. The user requires every existing feature category for launch and development one module at a time.

## Users

Working product assumption: individual job seekers managing and tailoring resumes. No additional audience segment or commercial adoption claim has been established.

## Capabilities and Constraints

React/Vite client, Express API, MongoDB. Vercel is the selected initial frontend host; production services are not provisioned. Preserve all current feature categories, secure identity and private user data. AI must not invent qualifications or substitute fabricated jobs for failed providers. M2 handles originals and factual review; M4 handles template-based PDF/DOCX output.

## Brand Commitments

The user approved the Module 1/2 mockup and then selected a warm beige/off-white background, readable sans typography, charcoal text and harmonious accents. The final reviewed concept uses deep teal actions and soft sage selected states. Implement this system consistently across module screens. Consult the user before a new design direction or feature removal.
